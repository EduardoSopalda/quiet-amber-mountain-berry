# Talk files

The preview only serves `public/talk`. Everything else lives here so it is not shipped to the room.

- `render/` — the film. `opening_anim.py` reads the approved slide and writes `public/talk/opening.mp4`. `export_layers.py` writes `layers/`.
- `layers/` — flat masks from the last layer export. Not on screen.
- `notes/` — the nine acts, the note for production, the note for Valeriia.
- `brand/` — dsm-firmenich masters. The file the stage uses is `public/talk/dsm-firmenich-black.svg`.
- `reference/` — stills and an earlier hold that no route requests.

`archive/` is the previous HTML deck and generated trials. Do not put those back on the front.

The approved slide and the script PDF stay in `attachments/`. That folder is the inbox. Do not tidy it.
