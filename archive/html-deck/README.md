## How to run it on stage

1. Open `index.html` locally or the hosted URL.
2. Press **F** (fullscreen).
3. Leave the title scene up while the chair introduces you.
4. First click / Space after you walk on.
5. **N** toggles speaker notes on the confidence screen only. Do not project notes to the room — use a second window or a printed cue sheet.
6. **T** pauses the on-screen timer.

Keyboard

| Key | Action |
|---|---|
| Space / → / click | Next |
| ← | Back |
| Home / End | First / last |
| F | Fullscreen |
| N | Notes |
| T | Pause timer |

## What this is doing that the static PPT does not

The talk is a descent: drawing → helicopter → street → plant floor → number → agent → road → night shift → question.

The pictures are the argument. Type is short enough to read from the back row. Motion is slow on purpose — you speak into still air, not over flying bullets.
